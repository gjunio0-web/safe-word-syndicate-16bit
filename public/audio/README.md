# Soundtracks Directory

Place your audio files (`.mp3`, `.wav`, `.ogg`, `.m4a`) in this directory with the following exact filenames to play custom tracks in game:

1. **Intro / Title Screen**: `intro.mp3` (or `intro.wav`, `intro.ogg`)
2. **Player Selection Screen**: `char_select.mp3` (or `char_select.wav`)
3. **Stage 1 Gameplay**: `stage1.mp3` (or `stage1.wav`)
4. **Stage 1 Boss Fight**: `stage1_boss.mp3` (or `stage1_boss.wav`)

If any track file is missing or not uploaded yet, the game will automatically use the built-in 16-bit retro synth audio engine as fallback!
